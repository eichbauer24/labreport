# Lab Report Marking Grid / Bewertungsraster Laborprotokoll

- English: `index.html`
- Deutsch: `de.html`

Both pages share the same saved practicals and class list. / Beide Seiten teilen sich gespeicherte Versuche und Klassenliste.

A marking grid for IB Chemistry lab reports, based on the four criteria of the scientific investigation: Research design, Data analysis, Conclusion and Evaluation, each worth 0–6 marks.

## Features

- **Basic and Expert level:** plain-language descriptors for simpler labs, or full descriptors for complete reports.
- **Choose criteria:** assess all four or only some, e.g. for practice labs.
- **Practicals with look-for points:** save lab-specific reminders for each criterion. "Separating salt, sand and water" is included.
- **Points per assignment:** the IB marks are converted into assignment points (default 3), rounded to whole, half or 0.1 points.
- **Feedback:** write "Well done" and "Next step" comments per criterion and copy a summary for the student.
- **Class list:** save results and copy them as a CSV table into Excel.

## Data storage

Everything is stored in the browser's local storage, on the device and in the browser you use. Nothing is sent to a server. Results do not sync between devices, and clearing browser data removes them.

## Publish on GitHub Pages

1. Create a new repository, e.g. `lab-report-grader`, or use a folder in an existing one.
2. Upload `index.html` and this `README.md`.
3. Go to **Settings → Pages**, choose **Deploy from a branch**, branch `main`, folder `/ (root)`.
4. After about a minute, the page is live at `https://<username>.github.io/lab-report-grader/`.

## Note

The band descriptors are paraphrased for quick marking. For moderation, use the official level descriptors in the IB *Chemistry Guide* (first assessment 2025).
